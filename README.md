# Interactive CSS-Based Web Navigation System

A responsive, interactive navigation system built purely with **HTML5 and CSS3** (no JavaScript dependencies).

## 🚀 Live Demo & Deployment
- **GitHub Pages:** Deployable directly via GitHub Pages (Branch: `main`, Folder: `/root`).
- **Main Showcase (`index.html`):** Complete interactive system with CSS-only hamburger menu, dropdown with `:focus-within`, `:has()` active state highlight, and light/dark theme support.
- **Academic Demo (`report-demo.html`):** The clean 5-section layout with `style.css` as documented in the Micro Project Report.

---

## 🛠 Features
- **Pure CSS Interactive Controls:** Checkbox hack for mobile hamburger toggling without JS.
- **Accessible Hover & Focus:** Keyboard-friendly dropdown navigation utilizing `:focus-within` and `:hover`.
- **Target Highlighting:** Modern `:has()` pseudo-class to track active sections smoothly.
- **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile viewport widths.
- **Dark Mode Support:** Automatic color scheme switching using `prefers-color-scheme`.
