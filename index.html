Project Overview

Redefining the Way We Experience Web Navigation.

"Spatial depth and responsive fluidity do not require heavy JavaScript frameworks—modern CSS3 transforms unlock native 60 FPS 3D architecture directly in the browser."

Developed for the Department of Computer Science & Technology (CST) academic micro-project (2026–27), this system investigates how declarative stylesheets can replace imperative scripting for interactive navigation, 3D visual storytelling, and state-driven UI controls.

By separating structural semantics (index.html and report-demo.html) from a single unified stylesheet (style.css), the platform achieves instant paint times, zero runtime script errors, and full cross-device compatibility.

01

Zero-Script Architecture

All menus, tabs, carousels, and 3D animations run purely on CSS selectors and GPU-composited transforms.

02

Mathematical Perspective

Calibrated camera focal distances and nested preserve-3d coordinate spaces prevent flat layer clipping.

03

Academic & Production Ready

Authored by Dhruv & Dhanesh (MITS Gwalior, 2026–27) with full WCAG 2.1 AA contrast and reduced-motion compliance.

CSS Technology Explorer

perspective • perspective-origin • transform-style 
.scene-container {
  perspective: 1300px;
  perspective-origin: 50% 50%;
}
.scene-rig {
  transform-style: preserve-3d;

Defines the virtual camera distance, vanishing point, and preserves a shared 3D coordinate space for nested children.
translateZ() • rotateX() • rotateY() • backface-visibility 
.card-face {
  transform: rotateX(8deg) rotateY(180deg) translateZ(48px);
  backface-visibility: hidden;
}
Positions elements along X, Y, and Z depth axes while culling rear-facing surfaces during 180° card flips.
@keyframes • animation • transition 
@keyframes floatLoop {
  0%   { transform: rotateX(11deg) translateZ(0); }
  100% { transform: rotateX(-11deg) translateZ(12px); }
}
.card {
  animation: floatLoop 6.5s ease-in-out infinite alternate;
  transition: transform 0.45s cubic-bezier(0.22, 1, 0.36, 1);
}
Drives continuous GPU-composited motion and smooth spring interpolation on user state changes.
:hover • :focus-visible 
.card:hover {
  animation-play-state: paused;
  transform: translateZ(24px) scale(1.04);
}
:focus-visible {
  outline: 2.5px solid #243F96;
}
Enables pointer-free interactive inspection and accessible keyboard navigation indicators.

Pure CSS State Machine: These tabs switch content instantaneously using hidden <input type="radio"> elements and the CSS general sibling combinator (~). Zero JavaScript event listeners are attached.
GPU Compositor Pipeline: All 3D rotations and translations operate exclusively on transform and opacity, allowing the browser to skip Layout and Paint phases for consistent 60 FPS motion.
Accessibility Guarantees: Every interactive component preserves semantic contrast (> 12:1 navy on warm ivory), keyboard tab order, and @media (prefers-reduced-motion: reduce) static fallbacks.
